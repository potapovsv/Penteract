# Анализ проекта Mondrian

## Обзор
**Mondrian** - это open-source OLAP (Online Analytical Processing) движок, написанный на Java. Проект принадлежит Pentaho и представляет собой сервер аналитической обработки данных.

## Архитектура проекта

### Структура Maven
- **Основной модуль**: `mondrian` (artifactId: mondrian)
- **Родительский POM**: `pentaho-mondrian-parent-pom` (версия 9.3.0.0-SNAPSHOT)
- **Версия проекта**: 9.3.0.1-LMX

### Основные компоненты

#### 1. Генерированный код (MondrianDef.java)
- Автоматически сгенерированные Java классы из XML схем
- Содержит определения для OLAP объектов:
  - `CubeUsages` - использование кубов
  - `CubeUsage` - конкретное использование куба
  - `CubeDimension` - измерения куба
- Методы для работы с XML и отладки:
  - `display()` - вывод структуры
  - `displayDiff()` - сравнение объектов
  - `displayXML()` - XML сериализация

#### 2. Конфигурация базы данных
- **Профили для тестирования**:
  - `embedded-mysql` - встроенный MySQL для интеграционных тестов
  - `load-foodmart` - загрузка тестовых данных FoodMart
  - `load-mondrian-properties` - загрузка свойств из файла

- **Настройки MySQL**:
  - Драйвер: `com.mysql.cj.jdbc.Driver`
  - База данных: `foodmart`
  - Пользователь: `mondrian`
  - Пароль: `password`
  - Порт: 3306

#### 3. Инструменты сборки
- **Maven плагины**:
  - `maven-clean-plugin` - очистка сгенерированных файлов
  - `maven-antrun-plugin` - генерация кода из XML
  - `docker-maven-plugin` - управление контейнерами MySQL
  - `exec-maven-plugin` - выполнение загрузчиков данных

#### 4. Тестирование
- **Интеграционные тесты**:
  - Использование Maven Failsafe Plugin
  - Запуск в фазе `integration-test`
  - Настройка системных свойств для JDBC

## Ключевые особенности

### OLAP функциональность
- Поддержка многомерных кубов данных
- Определение измерений, мер и иерархий
- Поддержка calculated members (вычисляемых элементов)
- XML-based конфигурация схем

### Архитектурные паттерны
1. **Code Generation** - автоматическая генерация Java классов из XML схем
2. **Template Method** - базовые методы display в генерированных классах
3. **Factory Pattern** - парсинг XML в Java объекты

### Интеграция с базами данных
- JDBC драйверы для различных СУБД
- Особая оптимизация для MySQL
- Поддержка различных типов источников данных

## Зависимости
- **Core**: Eclipse XOM (XML Object Model)
- **Database**: MySQL Connector/J
- **Utilities**: Guava 17.0
- **Testing**: XmlUnit 1.1

## Процесс сборки
1. **generate-sources** - генерация Java классов из XML
2. **pre-integration-test** - запуск MySQL и загрузка данных
3. **integration-test** - выполнение интеграционных тестов
4. **post-integration-test** - остановка контейнеров

## Заключение
Mondrian представляет собой зрелую OLAP систему с хорошо структурированной архитектурой, поддержкой различных СУБД и развитой системой тестирования. Проект использует современные подходы к генерации кода и контейнеризации для обеспечения стабильности интеграционных тестов.
